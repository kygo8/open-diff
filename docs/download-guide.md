# OpenDiff download guide

The full user-facing guide is written in Chinese (with English filename labels):

**[下载说明 / Download guide](./下载说明.md)**

Use that page (and the table at the top of every [GitHub Release](https://github.com/kygo8/open-diff/releases)) to pick the correct installer for Windows, macOS, or Linux.

## macOS note

If macOS says the app is **damaged** and should be moved to the Trash, that is usually Gatekeeper quarantine on an unsigned build—not a corrupt download. See the Chinese guide section **打开时提示「已损坏，无法打开」？** for `xattr -cr` steps.
