# OpenDiff 下载说明

面向普通用户：根据你的操作系统和芯片，选择 GitHub Releases 里正确的安装包。

**下载地址：** [GitHub Releases（Latest）](https://github.com/kygo8/open-diff/releases/latest)

文件名里的版本号会随发行变化（例如 `1.3.1`）。下面用 `*` 代替版本号；实际文件类似 `OpenDiff_1.3.1_windows_x64.msi`。

---

## 一分钟对照表

| 你的设备                                      | 该下载的文件（English filename）                                         | 不要下                                            |
| --------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------- |
| Windows 10/11（64 位，几乎所有电脑）          | `*_windows_x64.msi`（推荐安装）或 `*_windows_x64_portable.zip`（绿色版） | 任何 `darwin_*`、`linux_*`                        |
| Mac（Apple 芯片：M1 / M2 / M3 / M4 / M5 等）  | `*_darwin_aarch64.dmg`（推荐）或 `*_darwin_aarch64.app.tar.gz`           | `*_darwin_x64.*`、Windows、Linux                  |
| Mac（Intel 芯片）                             | `*_darwin_x64.dmg`（推荐）或 `*_darwin_x64.app.tar.gz`                   | `*_darwin_aarch64.*`、Windows、Linux              |
| Linux（Debian / Ubuntu / Linux Mint 等）      | `*_linux_amd64.deb`                                                      | `.rpm`（除非你用 Fedora/RHEL 系）、Windows、macOS |
| Linux（Fedora / RHEL / CentOS / openSUSE 等） | `*_linux_x86_64.rpm`                                                     | `.deb`（除非你用 Debian/Ubuntu 系）               |
| Linux（任意发行版，想免安装试用）             | `*_linux_amd64.AppImage`                                                 | 与你芯片不符的包（见下文）                        |

当前正式包均为 **64 位 x86_64 / amd64**（Windows / Linux）或对应的 **Apple Silicon / Intel Mac**。没有 32 位 Windows，也没有 Linux ARM（如树莓派）安装包。

## Windows

### 怎么确认是 64 位？

1. 设置 → 系统 → 关于（或「系统信息」）。
2. 「系统类型」应显示 **64 位操作系统**。  
   几乎所有近几年的 Windows 10/11 都是 64 位。OpenDiff 只提供 `windows_x64` 包。

### 该下哪个？

| 文件名                                | 适合谁                            | 怎么用                                             |
| ------------------------------------- | --------------------------------- | -------------------------------------------------- |
| `OpenDiff_*_windows_x64.msi`          | 大多数用户（推荐）                | 双击安装，开始菜单会出现 OpenDiff；可卸载。        |
| `OpenDiff_*_windows_x64_portable.zip` | 不想安装、想放 U 盘或任意目录运行 | 解压 zip，运行其中的可执行文件；不写系统安装目录。 |

### 不要下载

- `*_darwin_*`（那是 Mac）
- `*_linux_*`（那是 Linux）
- Source code (zip/tar.gz)（源码，给开发者编译用，不是安装包）

## macOS

### 怎么区分 Apple 芯片还是 Intel？

1. 屏幕左上角苹果菜单 → **关于本机**。
2. 看「芯片」或「处理器」：
   - 写着 **Apple M1 / M2 / M3 / M4 / M5…** → 选 **`darwin_aarch64`**（Apple Silicon）
   - 写着 **Intel** → 选 **`darwin_x64`**

选错芯片时，应用可能打不开或提示架构不兼容。

### 该下哪个？

| 文件名                                 | 芯片                  | 说明                                                     |
| -------------------------------------- | --------------------- | -------------------------------------------------------- |
| `OpenDiff_*_darwin_aarch64.dmg`        | Apple Silicon（推荐） | 打开 DMG，把 OpenDiff 拖到「应用程序」。                 |
| `OpenDiff_*_darwin_aarch64.app.tar.gz` | Apple Silicon         | 解压得到 `.app`，可放到「应用程序」；适合脚本/高级用户。 |
| `OpenDiff_*_darwin_x64.dmg`            | Intel Mac（推荐）     | 同上，拖到「应用程序」。                                 |
| `OpenDiff_*_darwin_x64.app.tar.gz`     | Intel Mac             | 解压得到 `.app`。                                        |

一般用户优先选 **`.dmg`**。若系统提示「无法验证开发者」，可在「系统设置 → 隐私与安全性」中允许打开，或右键 → 打开。

### 不要下载

- 另一架构的 `darwin_*` 包（M 系列不要下 `x64`，Intel 不要下 `aarch64`）
- Windows / Linux 包
- Source code 压缩包

## Linux

### 怎么确认架构？

在终端执行：

```bash
uname -m
```

- 输出 `x86_64` → 与当前发布的 `linux_amd64` / `linux_x86_64` 包匹配（同一类 64 位 PC）。
- 输出 `aarch64` / `arm64` → **当前 Releases 没有对应 Linux ARM 包**，请改用其他设备或自行从源码构建。

### 该下哪个？

| 文件名                            | 发行版 / 场景                                         | 怎么用                                                                             |
| --------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `OpenDiff_*_linux_amd64.deb`      | Debian、Ubuntu、Linux Mint、Pop!_OS 等                | `sudo apt install ./OpenDiff_*_linux_amd64.deb` 或双击用软件中心安装。             |
| `OpenDiff_*_linux_x86_64.rpm`     | Fedora、RHEL、CentOS Stream、Rocky、Alma、openSUSE 等 | `sudo dnf install ./OpenDiff_*_linux_x86_64.rpm` 或 `sudo zypper install ./…rpm`。 |
| `OpenDiff_*_linux_amd64.AppImage` | 任意常见 x86_64 Linux，想免安装                       | `chmod +x OpenDiff_*_linux_amd64.AppImage` 后直接运行；不写入系统包管理器。        |

说明：

- **`.deb` 与 `.rpm` 二选一**，按你的发行版选，不要两个都装。
- **AppImage** 适合试用或没有 root 权限时；需要自己处理桌面快捷方式（可选）。
- 文件名里 `amd64` 与 `x86_64` 都表示常见的 64 位 PC，不是两种不同芯片。

### 不要下载

- Windows / macOS 包
- 与发行版不匹配的包管理格式（例如 Ubuntu 不要优先装 `.rpm`，除非你清楚自己在做什么）
- Source code 压缩包（除非你要自己编译）

## 常见问题

**Q：Release 页面还有 Source code 怎么办？**  
那是源代码，不是给普通用户的安装包。请只下载上面表格里的 `OpenDiff_…` 资源。

**Q：我只有 32 位 Windows / 只有 ARM Linux？**  
当前正式 Release **不提供**这些架构的预编译包。

**Q：Mac 上 DMG 和 `.app.tar.gz` 有什么区别？**  
功能相同。DMG 更适合图形界面安装；`.app.tar.gz` 方便解压或自动化部署。

**Q：Windows 安装版和便携版怎么选？**  
日常使用选 **`.msi`**。需要免安装、多版本并存或放在移动目录时选 **`_portable.zip`**。

**Q：版本号对不上？**  
以 [Latest Release](https://github.com/kygo8/open-diff/releases/latest) 页面实际附件为准；本说明中的文件名模式长期有效。
